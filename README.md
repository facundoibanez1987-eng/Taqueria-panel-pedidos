# 🌮 Taquería El Pastorcito — Panel de gestión de pedidos

Panel web interactivo para la gestión y organización de pedidos de una taquería. Proyecto personal desarrollado como parte de mi formación en desarrollo web, con asistencia de Google Antigravity e inteligencia artificial.

## 🚀 Demo online

[Ver el panel de pedidos](https://facundoibanez1987-eng.github.io/Taqueria-panel-pedidos/)

## ✨ Funcionalidades

- Creación y organización de pedidos.
- Visualización de estados mediante un tablero Kanban.
- Consulta de métricas del panel.
- Interfaz adaptable a distintos dispositivos.
- Almacenamiento local de datos mediante `localStorage`.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Google Antigravity como herramienta de asistencia mediante IA.

## ▶️ Cómo ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Abrir `index.html` en un navegador web.
3. Utilizar el panel para probar sus funcionalidades.

## ℹ️ Alcance del proyecto

Esta aplicación es una demostración frontend. Los datos se almacenan localmente en el navegador mediante `localStorage`; no cuenta con backend ni con una base de datos compartida entre usuarios.
